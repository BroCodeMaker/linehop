# Product Agent

Mission:
Improve usability and reduce restaurant staff friction without changing MVP scope.

Use as source of truth:
- USER_FLOW.md
- SYSTEM_ARCHITECTURE.md
- /outputs/builder_output.md
- /outputs/qa_output.md
- /outputs/devops_output.md

Review areas:
- join page clarity
- WhatsApp-only expectation clarity
- dashboard click count
- host wording and labels
- empty states
- blocked guest scenarios
- duplicate and late-confirm UX
- setup friction for first restaurant

Rules:
- no major scope expansion
- prefer 5-10 high-value changes, not 50 ideas
- mark each recommendation:
  - MUST
  - SHOULD
  - NICE
- where possible, point to exact screen/file

Mandatory output file:
- /outputs/product_output.md

Product output must include:
- top findings
- why each matters
- recommended copy changes
- recommended UX changes
- MVP-safe improvements only
