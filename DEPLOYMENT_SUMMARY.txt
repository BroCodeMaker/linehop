💾 ENVIRONMENT VARIABLES (REQUIRED)
================================================================================

DATABASE_URL
  Source: Neon console
  Format: postgresql://user:pass@host.neon.tech/dbname
  Tip: Copy directly from Neon project settings

NEXTAUTH_SECRET
  Generate: openssl rand -base64 32
  Purpose: Security key for session encryption
  Keep: NEVER share this value!

NEXTAUTH_URL
  Example: https://myapp.vercel.app
  Purpose: Tells NextAuth where your app is hosted
  Must: Match your actual deployment URL

WHATSAPP_PROVIDER
  Options: "mock" (testing) or "twilio" (real)
  Start with: "mock" for initial testing
  Change to: "twilio" once you have API token

ADMIN_PASSWORD
  Purpose: For admin login at /app/login
  Username: "admin"
  Set to: Strong password (min 12 chars recommended)

📊 WHAT'S WORKING
================================================================================

API ENDPOINTS:
✅ POST /api/public/restaurants/{slug}/join
   Guest joins the queue

✅ GET /api/public/entry/{token}
   Check status (guest view)

✅ GET /api/restaurants
   List restaurants (admin)

✅ GET /api/restaurants/{id}/entries
   See queue (admin)

✅ POST /api/restaurants/{id}/entries/{id}/seat
   Seat guest (admin)

✅ POST /api/restaurants/{id}/entries/{id}/skip
   Skip guest (admin)

✅ POST /api/public/entry/{token}/cancel
   Cancel booking (guest)

✅ GET /api/internal/expire
   Trigger timeout check (cron)

✅ POST /api/webhooks/whatsapp
   WhatsApp callbacks (Twilio)

ADMIN DASHBOARD:

✅ View queue with status badges

GUEST PAGES:

BACKGROUND JOBS:

🐛 TROUBLESHOOTING
================================================================================

"502 Bad Gateway"
  ✓ Check Vercel deployment logs
  ✓ Verify DATABASE_URL is correct
  ✓ Try redeploying from Vercel dashboard

"Cannot connect to database"
  ✓ Test locally: psql "your-database-url"
  ✓ Check connection string in .env
  ✓ Verify Neon project is not paused

"Admin login not working"
  ✓ Check NEXTAUTH_SECRET is set
  ✓ Check NEXTAUTH_URL matches your domain
  ✓ Clear browser cookies
  ✓ Try incognito window

"WhatsApp not sending"
  ✓ Check WHATSAPP_PROVIDER = "mock" initially
  ✓ If using Twilio: verify API token
  ✓ Check Vercel logs for errors
